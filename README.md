# JSON Grove · JSON 查看与编辑器

可双击 **JSON查看器.html** 独立使用，也可执行 `jsonview 文件.json`，自动启动本地服务并在 Microsoft Edge 直接打开原文件。

## 使用

1. 双击 `JSON查看器.html`；如果默认浏览器不是 Edge，右键选择「打开方式 → Microsoft Edge」。
2. 点击「打开 JSON 文件」或拖入一个 JSON 文件，并允许文件读写。拖入后若只有读取权限，点击工具栏「授权编辑」。
3. 双击节点或点击「编辑字段」修改值；「编辑 JSON」可以修改字段名、增加 / 删除字段和调整结构。
4. 停止输入约 450 ms 后，合法 JSON 会自动写回原文件。确认右下角显示「已保存到原文件」再关闭页面。

## 功能

- 树形查看，默认二级展开，支持全部展开 / 折叠及一级至四级展开。
- 搜索字段和值，Enter / Shift+Enter 跳转匹配。
- 自动识别字符串中的 HTTP、HTTPS 和 www 地址；⌘ + 单击（Windows 使用 Ctrl）在新标签页打开，普通单击仍选择节点。
- 普通进入页面时右侧保持空白；从终端指定文件时自动加载该文件。
- 历史记录、置顶和移除；移除当前文件的记录时同步关闭右侧内容，不会自动打开其他文件，也不会删除原文件。
- 同一 Edge 配置、同一 HTML 地址的多个页面同步历史记录、置顶和移除；优先用页面间通知，无通知时可见页面约每 1.5 秒核对历史版本，切回窗口立即核对。隐藏或关闭页面后停止定时检查。
- 保存历史时在 IndexedDB 事务内读取最新记录，只合并本次修改的字段；其他页面新增的记录或置顶修改不会被旧列表覆盖。不同页面的未保存草稿分别保留。
- 删除使用持久标记，旧页面后续保存不会恢复已删除记录；再次明确打开原文件会建立新的历史记录。其他页面正在查看已删除记录时，无待保存修改则关闭右侧，有未保存编辑则保留当前内容，但不再恢复其历史记录。
- 打开文件时优先使用上次选择的位置；Edge 会记住该查看器的文件选择目录，并参考最近的历史文件位置。退回普通文件选择模式时，起始目录由浏览器管理。
- 自动把 JSON 对象或数组字符串解析成可展开的树。
- 查看与复制完整字段值、原始 JSON 和节点路径。
- 固定双栏布局，JSON 内容区独立滚动。
- 左下角「设置」可切换网页风格：默认（当前风格）、经典 Macintosh、Windows 95 / 98、复古报刊、老式档案馆、80 年代电脑、开发者工具、Linear 风格、Notion 文档风。点击选项即时预览并自动记住，同地址的其他页面同步切换。
- 网页风格与 JSON 内容配色独立：只调整侧栏、工具栏、按钮和弹层外观，保留 JSON 配色、字号、缩进和文件内容；修改 JSON 配色也不会改变网页风格。
- 右上方「缩进」弹出调整面板，支持滑块、输入 8–64 px 或加减按钮；即时调整每层树形缩进及辅助线，并记住上次设置。默认 28 px，可一键恢复；仅改变显示，不修改文件格式。
- 右上方「配色」提供自然浅色、经典浅色、海洋浅蓝、柔和紫灰、深邃夜色五套主题，默认经典浅色。点击「自定义」可修改背景、基础文字、字段名、字符串、数字、布尔值、空值和标点颜色；每套主题独立保存修改，并可恢复默认配色。
- 配色设置保存在当前浏览器的本地存储中，重新打开网页时恢复，不影响历史文件或原 JSON 内容。
- 右上方「Aa」弹出字号调整面板，支持滑块、输入 10–40 px，或用 − / + 每次调整 1 px；可重置为默认 15 px。树形内容、编辑器和配色预览即时生效，行高随之调整，层级缩进可单独调整。字号保存在当前浏览器的本地存储，下次打开自动恢复；独立 HTML 与服务地址分别保存。
- 支持字段编辑和完整 JSON 编辑，修改自动写回已授权的原文件；⌘ / Ctrl + S 可以立即重试保存。
- 修改 JSON 字符串解析出的内部字段时，写回仍保持原文件中的 JSON 字符串结构。只替换目标值，不重新序列化无关数字和格式。
- 格式错误或文件超过限制时不会写盘，保留草稿并提示；未保存内容会阻止直接切换文件，关闭页面时也会提示。
- 自动保存失败时，右下角显示失败状态；可以重试保存或重新授权。只有写入流成功关闭后才显示保存成功。
- 未写回的修改与无效输入尽量存入当前浏览器的历史草稿，重新打开后会提示手动核对和保存，不自动覆盖原文件。

## 从终端打开

同目录的 `jsonview` 使用与 `moye` 相同的本地服务方式，需要 Node.js 18 或更新版本，不需要安装第三方依赖。现有 `~/.local/bin/jsonview` 链接继续有效，无需重新安装。

```bash
jsonview "/完整路径/文件.json"
jsonview ./config.json
jsonview ../data/test.json
jsonview
jsonview --no-browser ./config.json
jsonview --stop
```

- 支持绝对路径、相对路径、中文、空格和符号链接；相对路径按终端的当前目录解析。含空格的路径需加引号；以 `-` 开头的文件名可使用 `jsonview -- -config.json`。
- 第一次执行时自动启动本地服务，后续命令复用。默认地址为 `http://127.0.0.1:5176/`，不会与 moye 默认的 5174 端口冲突。首次启动时可用 `JSONVIEW_PORT=5177 jsonview 文件.json` 指定其他端口。
- 指定文件会直接显示并允许编辑，不需要在网页重新选择或授权。仅接受已有且可读写的 UTF-8 `.json` / `.jsonc` 文件，最大 20 MB；内容必须是标准 JSON，不支持注释或尾随逗号。
- 不带文件路径时打开空白查看器。`--no-browser` 只打印访问地址，不自动打开 Edge；兼容 `--print-url` 作为其别名，二者都会启动或复用服务。
- 服务只监听本机 `127.0.0.1`，只有在终端明确打开过的文件可通过专属凭据读写；文件内容和绝对路径不会放入打开链接。普通打开按钮、拖放和原有编辑功能仍可使用。
- 关闭网页或终端后服务继续运行，与 moye 一致。确认修改已保存后执行 `jsonview --stop` 停止，下一次执行命令会重新启动。没有自动后台文件轮询或开机自启；原文件检查由可见网页发起。
- 服务状态保存在项目的 `.jsonview-runtime.json`（权限 600，Git 忽略）；关闭服务后清理。服务重启后凭据会更新，旧网页应通过重新执行命令得到的新链接打开。
- 服务方式下的历史记录和主题设置保存在该 HTTP 地址下的 Edge 存储中，与 `file://` 独立 HTML 的记录分开；更改端口也会切换浏览器存储。不会自动迁移原独立 HTML 的历史记录。
- 历史记录中的服务文件可在当前服务运行期间重新打开；重启服务后需用命令重新连接原文件。同一路径再次打开会复用已有历史记录及草稿，恢复的草稿需手动核对保存。
- `jsonview --help` 查看用法。脚本、`jsonview-cli.mjs`、`local-service.mjs` 和 HTML 需要保持在一起；项目移动后需更新安装链接。

手动安装（命令不存在时）：

```bash
mkdir -p "$HOME/.local/bin"
chmod +x "/Users/azzhu/Documents/ChatGPT/可视化json/jsonview"
ln -s "/Users/azzhu/Documents/ChatGPT/可视化json/jsonview" "$HOME/.local/bin/jsonview"
```

`~/.local/bin` 需要在终端的 `$PATH` 中，可以用 `command -v jsonview` 查看实际位置。

## 说明

- 首次升级多页面历史功能后，请刷新已打开的旧版页面；升级会保留原历史。旧页面关闭数据库连接后无法继续写入，避免绕过删除保护。同步依赖浏览器允许共享本地存储；不同 Edge 配置、不同 HTML 路径、独立 HTML 与 HTTP 服务地址之间不互通。

- 页面可见时约每秒检查原文件，切回窗口、切回标签页和从历史打开时立即检查；页面隐藏时停止定时检查。
- 没有待保存修改时，外部变更自动更新树形内容和未修改的编辑窗口，尽量保留展开状态和滚动位置；原文件格式错误时保留上次有效视图，修复后恢复。
- 网页和原文件都有修改时，自动保存暂停，两份内容均保留。点击保存状态或编辑窗口的「保存 / 处理冲突」，可以对照并复制网页草稿；「采用原文件」会放弃网页尚未保存的修改。
- 「放弃未保存修改」会再次确认，然后重新读取磁盘文件；已写回磁盘的内容不会回滚。
- 浏览器文件选择方式在不支持读写 API 或未获得写入权限时保持只读。终端服务方式直接由本地服务读写已指定的原文件，不依赖浏览器文件选择权限。独立 HTML 的历史保存与权限恢复仍受 Edge 的版本、隐私设置和文件页面权限限制。
- 写入前核对原文件内容并串行写入。服务方式使用同目录临时文件，写完后再次核对，再替换原文件，保留 BOM、格式与文件权限；不存在跨程序文件锁，请避免多处同时提交修改。浏览器崩溃或强制关闭时，尚未提交的修改仍可能丢失。
- 建议固定使用同一 HTML 路径和浏览器配置。更换位置、清理浏览器数据或使用无痕模式，可能无法保留原有历史。旧本地服务版历史不会自动迁移。
- 支持 UTF-8 标准 JSON（含 BOM），不支持注释或尾随逗号。文件最大 20 MB、100,000 个节点、512 层嵌套；每批显示 1,500 行，可继续加载。

HTML 已包含全部样式、图标和页面脚本，单独复制仍可双击使用，无需服务或 Node.js。终端命令模式需要本目录的启动脚本和服务文件。修改页面无需构建工具。
