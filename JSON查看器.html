让数据更好读

左下角「设置」可选择网页风格；右上角「配色」只调整 JSON 内容颜色，两者互不影响。

点击「打开 JSON 文件」或将文件拖入网页。历史记录保存在当前浏览器中，图钉可将常用文件置顶。

文件选择窗口会优先从上次打开的位置开始；重新打开网页后，也会参考历史文件的位置。普通文件选择模式下，起始位置由 Edge 自行管理。

右上方「配色」可以切换主题或自定义颜色；「Aa」可弹出字号面板，用滑块、加减按钮或输入数字调整大小。「缩进」可调整树形层级间距。配色、字号和缩进即时生效并自动记住。

获得写入授权后，双击节点或点击「编辑字段」可修改值；「编辑 JSON」可修改完整文件，支持字段增删和改名。字符串直接输入文字，其他类型输入有效 JSON。停止输入约 450 ms 后自动写回原文件，格式错误时保留草稿并暂停写入。搜索会自动展开匹配内容所在的路径。

「一级展开」显示根节点的直接字段；二级到四级逐层深入。搜索期间点击展开级别会清空搜索并切换层级。

双击 HTML 可独立使用；终端执行 jsonview 文件.json 会自动启动或复用本地服务，直接打开原文件。服务方式需要 Node.js 18+；关闭浏览器后服务继续运行，执行 jsonview --stop 停止服务。页面隐藏时停止文件检查。

授权读取原文件后，页面可见时约每秒检查一次外部修改。切回页面时也会立即检查。格式错误时保留上次有效的树形视图。

重新打开浏览器后，历史文件可能需要再次授权。如果当前浏览器限制本地页面的文件读取权限，会改用文件快照并明确提示无法自动同步；可重新选择文件更新内容。
